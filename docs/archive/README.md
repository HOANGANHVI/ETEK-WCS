# Kho tài liệu lịch sử

Giữ để truy xuất. Nội dung phản ánh thời điểm viết; **không** phải đặc tả hiện hành. Tài liệu hiện hành xem [mục lục](../README.md). Nội dung không được sửa khi chuyển vào đây, ngoài liên kết và đường dẫn.
Tên file nhắc trần trong văn bản cũ (ví dụ `OPEN_QUESTIONS.md`, nay ở [reports/agv-phase2-assessment](../reports/agv-phase2-assessment/OPEN_QUESTIONS.md)) được giữ nguyên.
